## Features

- **3D character & immersive landing** – Interactive scene with React Three Fiber
- **Smooth scroll & animations** – GSAP ScrollTrigger and Framer Motion
- **Projects showcase** – Horizontal scroll through AI/ML and full-stack projects with live demos and GitHub links
- **Tech Stack** – Interactive 3D tech sphere visualization
- **Certifications** – Glassmorphism cards with verified certification links
- **Career & Experience** – Timeline layout for roles and education
- **Skills** – Intelligence (ML, NLP, LLMs) and Insights (Data, Viz, SQL)
- **Contact** – Email and social links (GitHub, LinkedIn, Instagram)
- **Resume download** – One-click resume PDF download

## Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/Aayush-ujjwal/your-repo-name.git
   cd your-repo-name
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) (or the URL shown in the terminal).
